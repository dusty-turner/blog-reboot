Lesson 7: Independence

Devore 2.5.

Formulas

\(A\) and \(B\) are independent when \[P(A \cap B) = P(A)\,P(B)\]

Nothing new this lesson. Independence collapses the rules they already have.

Rule What they learned Under independence
Conditional probability \(P(A \mid B) = \dfrac{P(A \cap B)}{P(B)}\) \(P(A \mid B) = P(A)\)
Multiplication rule \(P(A \cap B) = P(A \mid B)\,P(B)\) \(P(A \cap B) = P(A)\,P(B)\)
Addition rule \(P(A \cup B) = P(A) + P(B) - P(A \cap B)\) \(P(A) + P(B) - P(A)P(B)\)

Caution. Mutually exclusive is the opposite of independent. Mutually exclusive means \(P(A \cap B) = 0\), so \[P(A \mid B) = \frac{P(A \cap B)}{P(B)} = \frac{0}{P(B)} = 0 \ne P(A)\] Learning that \(B\) happened rules \(A\) out completely, which is the most informative \(B\) can be. Independence is \(P(A \mid B) = P(A)\), where \(B\) tells you nothing.

Lesson 8: Discrete Random Variables

Devore 3.1, 3.2, 3.3.

Discrete or Continuous

Discrete You can list the values L8 unnamed
L9 Binomial
L10 Poisson

Continuous You cannot L11 unnamed
L12 Normal
L13 Exponential

Worth a discussion of what makes something discrete and what makes it continuous.

Notation

  • \(X\) is the random outcome of a process.
  • \(x\) is a specific value.
  • \(P\) takes an event. \(p\) takes a number.

\[p(x) = P(X = x)\]

The probability that the random outcome \(X\) equals the specific value \(x\).

Example Probability Mass Function (pmf)

\(X\) takes the values 0, 1, 5, 6:

\[p_X(x) = \begin{cases} 0.1 & \text{if } x = 0 \\ 0.2 & \text{if } x = 1 \\ 0.4 & \text{if } x = 5 \\ 0.3 & \text{if } x = 6 \\ 0 & \text{otherwise} \end{cases}\]

Same thing as a table:

\(x\) 0 1 5 6
\(p_X(x)\) 0.1 0.2 0.4 0.3

Cumulative Distribution Function (cdf)

  • \(F\) accumulates. It adds up every \(p_X(y)\) at or below \(x\).
  • \(x\) is still a specific value, and any real number is a legal input.

\[F(x) = P(X \le x) = \sum_{y \le x} p_X(y)\]

The probability that the random outcome \(X\) lands at or below the specific value \(x\).

Example Cumulative Distribution Function (cdf)

Same \(X\):

\[F_X(x) = \begin{cases} 0 & \text{if } x < 0 \\ 0.1 & \text{if } 0 \le x < 1 \\ 0.3 & \text{if } 1 \le x < 5 \\ 0.7 & \text{if } 5 \le x < 6 \\ 1 & \text{if } x \ge 6 \end{cases}\]

Same thing as a table:

\(x\) 0 1 5 6
\(p_X(x)\) 0.1 0.2 0.4 0.3
\(F_X(x)\) 0.1 0.3 0.7 1.0

Each jump is exactly \(p_X(x)\), and \(F\) holds flat everywhere else. It sits at 0.3 from 1 all the way to 5.

Expected Value

Back to the pmf:

\[p_X(x) = \begin{cases} 0.1 & \text{if } x = 0 \\ 0.2 & \text{if } x = 1 \\ 0.4 & \text{if } x = 5 \\ 0.3 & \text{if } x = 6 \\ 0 & \text{otherwise} \end{cases}\]

\(x\) 0 1 5 6
\(p_X(x)\) 0.1 0.2 0.4 0.3

\[E(X) = \sum_x x\,p_X(x)\]

One term per value, weight times value:

\[E(X) = (0)(0.1) + (1)(0.2) + (5)(0.4) + (6)(0.3) = 4\]

Variance

Two formulas, same answer. The definition:

\[V(X) = \sigma^2 = \sum_x (x - \mu)^2 p_X(x) = E[(X - \mu)^2]\]

\[V(X) = (0-4)^2(0.1) + (1-4)^2(0.2) + (5-4)^2(0.4) + (6-4)^2(0.3) = 5\]

The shortcut:

\[V(X) = E(X^2) - [E(X)]^2\]

\[E(X^2) = (0)(0.1) + (1)(0.2) + (25)(0.4) + (36)(0.3) = 21\]

\[V(X) = 21 - 4^2 = 5\]
