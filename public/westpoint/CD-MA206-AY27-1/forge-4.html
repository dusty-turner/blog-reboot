Lesson 9: Binomial Distribution

Devore 3.4.

R-Lite

R-Lite on Canvas.

  • Ensure cadets have it downloaded.
  • Demonstrate how to use it in class.
  • Will need for WPR I.

Opening as a Counting Problem

Shoot 5 free throws. Probability of making one is 75%. What is the probability of making exactly 3?

\[(0.75)(0.75)(0.75)(0.25)(0.25) = (0.75)^3 (0.25)^2 = 0.0264\]

How many ways can we choose 3 makes out of 5 attempts? 5 choose 3.

\[\binom{5}{3} = 10\]

Those 10 ways are mutually exclusive, so the addition rule applies and the probabilities add.

\[P(X = 3) = \binom{5}{3} (0.75)^3 (0.25)^2 = 10(0.0264) = 0.264\]

Great place to tie in:

  • L5 counting
  • Multiplication rule from L7 independence
  • Addition rule from L4

Now we can generalize:

Replacing 5 with \(n\), 3 with \(x\), and 0.75 with \(p\) gives the pmf:

\[p(x) = \binom{n}{x} p^x (1-p)^{n-x}\]

NoteFully specify the distribution

\[X \sim \text{Binom}(n = 5,\ p = 0.75)\]

  • Designate the random variable. \(X\) is the number of makes in 5 attempts.
  • Name the distribution. Binomial.
  • Specify the parameters. \(n = 5\) and \(p = 0.75\).

In R-Lite

\(X \sim \text{Bin}(5, 0.75)\). dbinom is the pmf, pbinom is the cdf.

R-Lite
\(P(X = 3)\) dbinom(3, 5, 0.75) 0.2637
\(P(X \le 3)\) pbinom(3, 5, 0.75) 0.3672
\(P(X < 3)\) pbinom(2, 5, 0.75) 0.1035
\(P(X > 3)\) 1 - pbinom(3, 5, 0.75) 0.6328
pbinom(3, 5, 0.75, lower.tail = FALSE) 0.6328
\(P(X \ge 3)\) 1 - pbinom(2, 5, 0.75) 0.8965
pbinom(2, 5, 0.75, lower.tail = FALSE) 0.8965

Mean and Variance

\[\begin{aligned} \mu = E(X) &= np = 5(0.75) = 3.75 \\ \sigma^2 = V(X) &= np(1-p) = 5(0.75)(0.25) = 0.9375 \\ \sigma &= \sqrt{np(1-p)} = \sqrt{0.9375} = 0.968 \end{aligned}\]

NoteWhere these come from

Start from the L8 definition and substitute the binomial pmf.

\[E(X) = \sum_x x\,p(x) = \sum_{x=0}^{n} x \binom{n}{x} p^x (1-p)^{n-x}\]

The \(x = 0\) term is zero, so start at 1. Use \(x\binom{n}{x} = n\binom{n-1}{x-1}\) and pull \(np\) out front.

\[E(X) = np \sum_{x=1}^{n} \binom{n-1}{x-1} p^{x-1} (1-p)^{n-x}\]

Let \(y = x - 1\). What is left is a full binomial pmf on \(n-1\) trials, so it sums to 1.

\[E(X) = np \sum_{y=0}^{n-1} \binom{n-1}{y} p^{y} (1-p)^{(n-1)-y} = np\]

For the variance, the same trick twice gives

\[E[X(X-1)] = n(n-1)p^2 \quad\Longrightarrow\quad E(X^2) = n(n-1)p^2 + np\]

Then use the L8 shortcut \(V(X) = E(X^2) - [E(X)]^2\).

\[V(X) = n(n-1)p^2 + np - (np)^2 = np - np^2 = np(1-p)\]

A Fun Exercise

  • Pass out quarters.
  • Have everyone flip until someone stops a streak of all heads or all tails.
  • Find the probability of hitting that many or more.
  • Ask the class if we think there is something up with their flipping ability.
  • Just for fun. It gets them starting to think about hypothesis testing. Was this so extreme we do not believe it? How unlikely would it have to be before we stopped believing?

Lesson 10: Poisson Distribution

Devore 3.6.

What Cadets Should Look For

  • A rate, given per unit of time, length, or area.
  • A window, the interval the count is taken over.
  • A count with no fixed \(n\). Nothing caps how many can happen.

Parameters

\(\lambda\) is the rate. \(t\) is the length of the window. The distribution depends only on their product.

\[\mu = \lambda t\]

Cadets arrive at the counter at \(\lambda = 2.5\) per hour. Over a \(t = 2\) hour window, \(\mu = 5\).

NoteFully specify the distribution

\[X \sim \text{Pois}(\mu = 5)\]

  • Designate the random variable. \(X\) is the number of arrivals in 2 hours.
  • Name the distribution. Poisson.
  • Specify the parameter. \(\mu = \lambda t = 2.5(2) = 5\).

In R-Lite

dpois is the pmf, ppois is the cdf.

R-Lite
\(P(X = 3)\) dpois(3, 5) 0.1404
\(P(X \le 3)\) ppois(3, 5) 0.2650
\(P(X < 3)\) ppois(2, 5) 0.1247
\(P(X > 3)\) 1 - ppois(3, 5) 0.7350
ppois(3, 5, lower.tail = FALSE) 0.7350
\(P(X \ge 3)\) 1 - ppois(2, 5) 0.8753
ppois(2, 5, lower.tail = FALSE) 0.8753

Mean and Variance

\[\begin{aligned} \mu = E(X) &= \lambda t = 2.5(2) = 5 \\ \sigma^2 = V(X) &= \lambda t = 5 \\ \sigma &= \sqrt{\lambda t} = \sqrt{5} = 2.236 \end{aligned}\]

The mean and the variance are the same number.

NoteWhere these come from

Start from the L8 definition and substitute the Poisson pmf.

\[E(X) = \sum_x x\,p(x) = \sum_{x=0}^{\infty} x \, \frac{e^{-\mu} \mu^x}{x!}\]

The \(x = 0\) term is zero, so start at 1. Cancel the \(x\) against \(x!\) and pull \(\mu\) out front.

\[E(X) = \mu \sum_{x=1}^{\infty} \frac{e^{-\mu} \mu^{x-1}}{(x-1)!}\]

Let \(y = x - 1\). What is left is a full Poisson pmf, so it sums to 1.

\[E(X) = \mu \sum_{y=0}^{\infty} \frac{e^{-\mu} \mu^{y}}{y!} = \mu\]

For the variance, the same trick twice gives

\[E[X(X-1)] = \mu^2 \quad\Longrightarrow\quad E(X^2) = \mu^2 + \mu\]

Then use the L8 shortcut \(V(X) = E(X^2) - [E(X)]^2\).

\[V(X) = \mu^2 + \mu - \mu^2 = \mu\]

Lesson 11: Continuous Random Variables

Devore 4.1, 4.2.

Expectations

Cadets should be able to:

  • Solve for an unknown constant \(k\) in a pdf.
  • Fully define the cdf.
  • Find probabilities from the pdf and from the cdf.
  • Explain why \(P(X = c) = 0\).
  • Compute expected value, variance, and standard deviation.

Worked Example

\[f_X(x) = \begin{cases} k x & 0 \le x \le 4 \\ 0 & \text{otherwise} \end{cases}\]

Solve for \(k\). Total area is 1.

\[\int_0^4 k x \, dx = k \frac{x^2}{2} \bigg|_0^4 = 8k = 1 \quad \Longrightarrow \quad k = \frac{1}{8}\]

Fully define the cdf. Integrate the pdf from the left edge of the support.

\[F_X(x) = \int_0^x \frac{1}{8} t \, dt = \frac{x^2}{16}\]

\[F_X(x) = \begin{cases} 0 & x < 0 \\ \dfrac{x^2}{16} & 0 \le x \le 4 \\ 1 & x > 4 \end{cases}\]

Find a probability two ways. \(P(1 \le X \le 2)\).

\[\begin{aligned} \text{pdf} \quad & \int_1^{2} \frac{1}{8} x \, dx = \frac{x^2}{16} \bigg|_1^{2} = \frac{4 - 1}{16} = 0.1875 \\ \text{cdf} \quad & F(2) - F(1) = \frac{4}{16} - \frac{1}{16} = 0.1875 \end{aligned}\]

Why \(P(X = c) = 0\). The integral over a single point has no width.

\[P(X = c) = \int_c^c f(x) \, dx = 0\]

So \(\le\) and \(<\) give the same answer here, unlike L8 through L10.

Expected value and variance.

\[\begin{aligned} E(X) &= \int_0^4 x \cdot \frac{1}{8} x \, dx = \frac{1}{8} \cdot \frac{x^3}{3} \bigg|_0^4 = \frac{8}{3} = 2.667 \\ E(X^2) &= \int_0^4 x^2 \cdot \frac{1}{8} x \, dx = \frac{1}{8} \cdot \frac{x^4}{4} \bigg|_0^4 = 8 \\ V(X) &= E(X^2) - [E(X)]^2 = 8 - \frac{64}{9} = \frac{8}{9} = 0.889 \\ \sigma &= \sqrt{0.889} = 0.943 \end{aligned}\]
